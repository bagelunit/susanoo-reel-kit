# The bar

Paste this section into every shot builder's brief. It is short on purpose.

A reel made with this kit has to beat the reels the viewer scrolled past a second ago. The template gets you a clean, readable frame. Making it worth watching is your job.

## Five promises every reel keeps

| Promise | What it looks like on screen | How you know you broke it |
|---|---|---|
| **An idea only this script could have** | The airport reel shows prices flipping $4 → $19 on the word "expensive", not a generic "money" icon | You could paste the frame into a different reel and nobody would notice |
| **Designed, not assembled** | Deliberate colour, real depth (shadow, overlap, light), crisp type, objects with weight | A still of it would embarrass you on your own feed |
| **Always alive** | Every landed object keeps moving a little: a needle drifts, a cursor blinks, a clock ticks | Two stills 0.6 s apart look the same anywhere on screen |
| **Moves with weight** | Things drop, slam, spring past their mark and settle; neighbours flinch when something lands | Something appears or vanishes with no motion in between |
| **Gets it in half a second** | One focus at a time, readable with the sound off | You need the voiceover to know where to look |

## Questions to ask about every shot

1. **The thumb test.** Would this frame stop a fast scroll? What's moving at 0.0 s?
2. **The mute test.** Turn the sound off. Does the picture alone carry the sentence?
3. **The swap test.** Could this visual belong to a different script? If yes, it's generic: find the object this script implies.
4. **The rewatch test.** Is there one moment per reel someone would screenshot or replay? Plan it, and put it on a word.
5. **The kid test.** Could a twelve-year-old repeat the idea back after one watch?
6. **The pro test.** What would a motion designer add here? Usually a secondary motion, a better hand-off, or texture.

## Before you call a shot done

- [ ] It's the best visual you found for these words, not the first one.
- [ ] One focus, a full stage, everything alive.
- [ ] Every stressed word changes something.
- [ ] You'd post a still of it.

If a box isn't ticked, keep going. Strong reels carry a lot of custom shot code per second of video; effort shows.
