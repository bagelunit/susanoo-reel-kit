# Prompts to copy and send

Copy a prompt, replace the parts in [square brackets] with your own, delete any line you do not care about, and send it to Claude Code. A line you leave blank or delete is a question Claude will ask you instead, so you never have to fill everything in.

The kit's setup prompt (the one you send in the kit's own folder) is in the kit's README. These two are for a brand folder, which is a copy of this template.

## 1. Set up this brand

Send this once, in a fresh copy of the template, after opening Claude Code inside it.

```
Set up this brand. Follow the first-run brand setup in CLAUDE.md. Use my answers below where I filled them in, and ask me the rest as multiple-choice questions (a few at a time, recommended option first).

About me
- My name: [your name]
- Who approves the reels: [me / someone else: their name]

About the brand
- Brand or client name: [name]
- Instagram handle: [@handle / no account yet]
- Website (read it and suggest answers, but I confirm each one): [https://... / skip]
- What the brand does, in one line: [one line]
- Who it talks to: [one line]

Look
- Accent colour: [#hex / pick from your ready themes / read it from my logo]
- Background and ink colours (optional): [#hex, #hex]
- Logo file: [full path to a PNG or SVG / none yet]
- Fonts: [use the kit's fonts / display: ..., body: ...]
- Presenter: [sticker avatar, pose folder at: path / sticker avatar, make one later / no host / the kit's drawn presenter]

Sound
- Voice: [pick an ElevenLabs voice together now / use the voice already saved / my own recording / decide later]
- Words the generated voice must never say: [words, or none]
- Names that need spelling by sound: [name = how it sounds, or none]

How it ends
- Call to action: [Save this / Follow for more / Visit the link in bio]  (a "comment a keyword" call to action only after I have tested the DM auto-reply)
- Keep a private local history of this folder (never uploaded): [yes / no]
- Tell me at the start of a session when a newer kit version is out: [yes / no]

Rules: write only what I confirm. Do not put any number, result, price or client name into brand/facts.md unless I state it here and you read it back to me. Do not ask for or show any API key. When done, show me a short summary of what you wrote and anything still empty.
```

## 2. Make a reel

Send this each time you want a reel, in the brand folder, after the brand is set up.

```
Make a reel for [brand name] on [topic, in one line].

What I want from it
- The one goal: [save / share / follow / lead]
- Angle (optional, otherwise suggest one that differs from my last post): [result first / self-proving / contrarian / pain first / something breaks]
- Length: [about 30 seconds / 45 seconds]
- Style: [Print / 3D / Talking head / not sure, recommend one and ask me]

What is true and OK to say
- Facts to use: [fact 1 / fact 2 / none yet, so use no numbers]
- Something only we can say (our own proof, story or twist): [one or two lines]
- Things to avoid: [words, claims, competitors, topics]

If I already have a script
- [paste it here and use it word for word, or delete this part]

Follow the house rules in CLAUDE.md. Check the first-frame hook checklist before the script. Run the voice credit check and tell me the number before I approve. Stop at each approval gate (script, visual plan, final) and wait for my yes. Do not post, schedule or send anything; I will post it myself.
```

## 3. After posting (a day or more later)

```
Read these numbers for [reel name] and tell me what to do next. Judge them against this brand's own median, not outside benchmarks. Views: [..], 3-second hold: [..], saves: [..], shares: [..], comments: [..], follows from this reel: [..]. Give me two actions, not twelve, and say what the data cannot tell us.
```

## Weekly batch (optional)

```
Plan this week's reels for [brand name]: [2 / 3] reels. Give each its own goal and a different angle, write all the scripts, and take them to the script gate together. I will approve each one separately. Topics I have in mind: [topics, or suggest some from brand/swipe.md and brand/plan.md].
```
